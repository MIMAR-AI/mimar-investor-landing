# MIMAR Investor Landing

Public investor overview for MIMAR, a FoundifAI product.

## Serivox deployment

Connect the `MIMAR-AI/mimar-investor-landing` repository through the Serivox GitHub App, then configure:

- Install command: `npm ci`
- Build command: none
- Start command: `npm start`
- Health endpoint: `/healthz`
- Custom domain: `investor.mimarai.net`

The app listens on the platform-provided `PORT` environment variable.
